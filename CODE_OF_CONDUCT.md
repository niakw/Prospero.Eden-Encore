# Code of Conduct

Prospero.Eden Encore aims to keep project collaboration technical, respectful and useful.

## Expected behavior

Participants should:

- discuss ideas and code without personal attacks;
- give technical criticism with enough context to act on it;
- respect contributors regardless of background, identity or experience;
- avoid harassment, threats, discrimination, doxxing or sustained disruption;
- respect licenses, copyright and the project's legal-use boundaries;
- avoid posting console keys, proprietary firmware, copyrighted game files or instructions whose
  purpose is piracy.

## Unacceptable behavior

Examples include harassment, discriminatory language, sexualized or threatening conduct, deliberate
misrepresentation of another contributor, publishing private information, spam, and repeatedly
derailing technical discussions after moderation requests.

## Enforcement

The repository maintainer may edit, hide, lock or remove content and may restrict participation when
necessary to protect contributors or the project.

For ordinary moderation concerns, contact the repository owner privately through a contact method
listed on the maintainer's GitHub profile. Do **not** use a public issue to report private personal
information.

Security vulnerabilities are handled separately under [SECURITY.md](SECURITY.md).

## Scope

This policy applies to participation in this repository and in public spaces where someone is
clearly representing Prospero.Eden Encore.

The goal is simple: keep collaboration safe, lawful and focused on improving the software.
